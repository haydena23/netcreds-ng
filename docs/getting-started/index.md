# Getting started

Three short pages take you from nothing to reading your first results:

1. **[Installation](installation.md)**: Python requirements, optional extras, and the packet-capture driver needed for live capture.
2. **[Quickstart](quickstart.md)**: analyse a capture, read the output, write a report, and simulate a brute-force attack with the test SDK to see alerts.
3. **[Core concepts](concepts.md)**: findings, kinds, risk levels, tags, and the difference between a *credential* and an *authentication event*. Read this before you act on results.

If you used the original `net-creds`, see [Legacy mode](../guide/legacy.md) for the option that reproduces its output exactly, and [Changes from net-creds 1.x](../guide/legacy.md#what-changed-outside-legacy-mode).
